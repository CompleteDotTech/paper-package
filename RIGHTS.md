# Reuse and citation

## Original project code

Original source code and code-specific configuration authored for this repository are licensed under the [GNU Affero General Public License, version 3 only](LICENSE) (`AGPL-3.0-only`). This includes original Python programs, tests, shell scripts, dependency specifications, and GitHub Actions workflow configuration, whether in the frozen research package or later extensions. The grant covers only material for which the project contributors can grant rights. Preserve applicable copyright and license notices when reusing it.

The original root [README.md](README.md) and [REPRODUCE.md](REPRODUCE.md) are byte-preserved research artifacts. Their statement that the original package granted no new code license describes the package at the time it was frozen. This document and `LICENSE` state the current grant for original project code; they do not alter the archived files or the rights to other content.

## Research and third-party material

| Material | Rights boundary |
| --- | --- |
| Manuscripts, protocols, reports, explanatory prose, and bibliography | No reuse license is granted here for original research writing. Citation is welcome; reproduction of substantial text requires the applicable rights holder's permission unless an independent exception applies. |
| Figures, rendered PDFs, images, tables, and generated research outputs | The code license does not apply to these artifacts or to source text and data reproduced in them. Follow any separate notice for their inputs. |
| Saved prompts, requests, model responses, prediction journals, and audit records | These are research evidence. They may contain source excerpts or other third-party content. The code license does not grant rights to redistribute or repurpose their contents. |
| SciFact, S2ORC-derived abstracts, DBLP–ACM, Ditto, and other upstream material | Upstream rights and attribution remain in force. See the [source and data notes](supplementary/REFERENCES_AND_DATA.md) and preserved [SciFact](supplementary/licenses/SCIFACT_LICENSE.md), [DBLP–ACM](supplementary/licenses/DBLP_ACM_NOTICE.md), and [Ditto](supplementary/licenses/DITTO_APACHE_LICENSE.txt) notices. |

When a file combines original code with evidence text or third-party data, the AGPL grant covers only the separable original code. It does not replace upstream licenses, data notices, model-service terms, or permissions needed for embedded material. File location alone does not change these boundaries.

## Cite the repository

Use [CITATION.cff](CITATION.cff) to cite this package and include the exact commit or release used when reproducibility matters. Cite underlying datasets and publications separately using the [source and data notes](supplementary/REFERENCES_AND_DATA.md). Citation metadata identifies the credited author and affiliation; it does not assert ownership by that organization or grant reuse rights to research artifacts.
