We deliberately do not repeat these as new contributions.

| New mechanism | Closest existing work | Substantive difference |
|---|---|---|
| H1: Unlabeled label-shift correction | Prevalence projections and probability calibration | Estimate a target class prior from unlabeled target predictions and development confusion, then reweight class probabilities; neither projections nor temperature tuning. |
| H2: Dependence-robust lineage certificates | Reliability H3 exact independent-primitive evaluation | Optimize over all joint distributions matching supplied marginals; remove primitive independence rather than merely increase the exact-evaluation cap. |
| H3: Protected-fact minimal source repair | Alternative-proof retraction | Choose a minimum-cost intervention that destroys every target proof while preserving at least one proof of every protected fact; not propagation after a predetermined withdrawal. |

The latest results show failed semantic risk calibration, costly redundant judgments, an explicit false-independence counterexample, bounded structural optimization, and global preprocessing costs excluded from incremental savings. These findings motivate the five tests. All algorithms are opt-in research modules; no default compiler, production graph policy, archived raw calls or original manuscript changes.

## H1: Unlabeled label-shift correction

Hypothesis: adapting class priors without test labels reduces wrong emitted relations at matched volume without materially reducing correct-edge recovery. On valid development base1 outputs build a three-class hard-prediction confusion matrix, with one pseudo-observation per predicted class in each true-class column. Source priors receive one pseudo-observation per class. Estimate target priors q on the simplex by minimizing ||Cq-m||^2 + 0.01||q-p_source||^2, where m is the valid test predicted-label frequency. Solve all nonempty simplex faces with fixed label-order ties. Reweight each valid probability vector by q/p_source and normalize; keep operational failures as failures. This is a regularized BBSE-inspired adaptation, not an exact reproduction of published BBSE or a calibrated posterior guarantee.

Compare unchanged single-view argmax against corrected argmax at natural volume and at k=min(the two positive-edge counts), ranking by chosen-label score then candidate ID. Positive labels are SUPPORTS and REFUTES. Primary conjunction: at least 98% of baseline naturally correct edges retained, and at least 20% fewer wrong edges than baseline at matched k. Report labels, selected IDs, full-denominator recall, errors, abstentions, source/estimated/observed test priors, confusion diagnostics and recorded tokens. Gold-based test priors appear only as evaluation diagnostics. Include a known-confusion label-shift control and a conditional-shift control showing that marginal matching can be wrong. Empty or unidentifiable development/target inputs must fail closed or explicitly retain the unchanged predictor, never silently invent priors.

## H2: Dependence-robust lineage certificates

Hypothesis: marginal-only bounds prevent unsupported admissions caused by falsely assuming primitive independence. A fact is an OR of nonempty AND proofs. For at most eight primitive atoms enumerate Boolean worlds, constrain nonnegative world masses to sum to one and match each supplied primitive marginal, and minimize/maximize the fact indicator. Use a linear-programming solver, then independently verify rational dual inequalities over every world, correcting only the dual constant outward if necessary. Admission at 0.95 uses the rational lower certificate, not a rounded float or a nominal optimizer success flag. Caps or solver failure return conservative Frechet/union bounds with an explicit fallback label; never a partly solved exact probability.

Run 128 seeded arbitrary joint-distribution fixtures with 2-6 atoms and random proof families; compute actual truth directly from the supplied joint masses. Compare the existing independence-based evaluator and dependence-robust bounds. Also verify analytical two-atom AND/OR bounds across a fixed marginal grid, duplicate/order invariance, empty proof families and cap/failure behavior. Primary: no certified interval excludes supplied truth; no lower-certificate false admission; analytical endpoints agree within 1e-8; and at least one false independence-based admission is prevented. Include two distinct atoms that are perfectly correlated with marginal 0.8 (OR truth 0.8 versus independent 0.96). Report wider intervals and lost admissions as the cost of weaker assumptions. Incorrect marginals remain an explicit unfixable control; Jev scores are not supplied truth marginals.

## H3: Protected-fact minimal source repair

Hypothesis: provenance-aware exact intervention reduces repair cost without destroying designated protected facts. Given a target OR-of-AND proof family, protected fact proof families, and positive integer source-withdrawal costs, find a minimum-cost source set intersecting every target proof while leaving at least one complete proof per protected fact. Branch on a currently unhit target proof; prune protected-fact destruction and dominated cost. Bound at 16 atoms and 65,536 search states. On exhaustion stage, never return a partial optimum. Tie-break on the sorted withdrawal tuple.

Compare with cost-normalized greedy target-proof coverage that rejects actions destroying protected facts, and an independent exhaustive subset oracle. Run 128 seeded eight-atom fixtures with 3-8 target proofs, 0-3 protected facts and costs 1-9. Primary: no feasibility, protection or optimal-cost mismatch; no cost regression where greedy completes; and strict lower cost or recovery from greedy dead-end on at least 5% of oracle-feasible fixtures. Include a fixed greedy trap, an impossible protected-target conflict, redundant proofs, input-order invariance, invalid costs, cap exhaustion and empty target tests. No source is actually deleted; protected means designated by the fixture, not independently proven true. Costs are supplied units, not dollars or measured human labor.

## H4: Bipartite min-cut conflict optimization

Hypothesis: an opt-in bipartite route solves dense conflict components that the four-cut-vertex policy stages. Validate and two-color each explicit graph component; for bipartite components up to 256 vertices reduce minimum-weight vertex cover to integer max flow, with cross capacities greater than total priority. The complement is the selected independent set. Nonbipartite components retain the existing cutset/enumeration/staging route. Return a verifiable cover/flow certificate; supplied nonnegative integer priorities are not truth probabilities.

Test 128 seeded small weighted bipartite graphs against independent subset enumeration, plus general-graph fallback controls. Test complete bipartite graphs K(8,9), K(16,16), K(32,32), K(64,64), K(128,128) with analytical weighted optima; compare the actual previous solver and priority greedy. Primary: zero consistency/optimality failures on supported fixtures, no utility regression versus the previous solver, and nonzero optimal utility without staging on every listed large bipartite fixture. Test permutation/edge-direction/duplicate invariance, disconnected graphs, zero weights, odd cycles, dense nonbipartite staging, over-cap graphs and a high-priority false assertion. Do not infer semantic accuracy or unrestricted graph scalability.

## H5: Indexed interval conflict construction

Hypothesis: key-partitioned interval sweeping removes unnecessary conflict checks while preserving exactly the prior scope/interval semantics. Partition supported assertions by (subject,predicate,scope), sweep start times, expire end<=start for half-open intervals, and test semantic collision only among active overlapping assertions. Preserve None endpoints as unbounded and stage unknown/malformed inputs. Compare against the existing pairwise conflict function on all supported pairs; IDs must be nonempty and unique.

Run 128 seeded small cases with bounded/unbounded intervals, opposite polarity, declared functional collisions, multiple keys/scopes, duplicate facts and invalid qualifiers. Independently check bounded interval truth by enumerating integer instants. Sparse workload: 128 independent keys, 16 assertions per key, start i, end i+3, alternating objects, positive functional relations; include size prefixes 256,512,1024,2048. Dense control: 256 mutually overlapping same-key assertions with distinct objects. Primary: zero edge/staging mismatches and at least 95% fewer semantic pair checks on the 2048-row sparse case. Count validation, grouping and sorting separately in the explanation; report actual end-to-end construction timing over five repeats separately from deterministic results. No speedup percentage may be inferred from pair-check savings; retain dense worst-case behavior.
