# Ten operational hypotheses for Jev graph synthesis

Protocol version 1; source baseline: `2c5184390bfa63740b44fb556a270418a6c1d882`.

This is an exploratory extension of previously inspected, published-in-repository observations, NOT an independent preregistration. None of the hypotheses is represented as newly invented mathematics. The purpose is to falsify concrete architectural predictions. Preserve the frozen study, original inventory, and existing results unchanged. Do not promote experimental policies into the production/default graph compiler.

## Evidence and isolation

T01–T06 reuse only exact, hash-verified archived Jev requests and responses. They make zero new service calls. Original evaluation examples remain evaluation examples. Build connected components using record IDs or claim/document IDs across calibration and evaluation, without gold labels. Remove calibration components touching evaluation. Report all retained/dropped rows and component counts. The original few-shot formulation was selected using the earlier calibration set, so this additional purge does not create pristine independent conformal calibration. T07 is a conditional score-resampling simulation; T08 is a cache simulation; T09–T10 test actual GraphStore behavior with explicitly synthetic decisions. These are not new Jev benchmarks or a KARMA replication.

Inference/selection functions must not receive evaluation gold. Gold is allowed only in calibration fitting, evaluation, and explicitly marked synthetic truth generators. Use seed 20260918, 500 paired component bootstrap replicates for descriptive intervals, 256 six-node identity worlds per arm, 128 random-review controls, and fixed thresholds. Do not tune hypotheses after viewing the results. Report null, harmful, and mixed outcomes. Descriptive intervals are not simultaneous confidence intervals or confirmatory tests across ten hypotheses. Shared-source grouping is a conservative dependence proxy, not proof of exchangeability.

## Hypotheses and fixed primary comparisons

| ID | Operational hypothesis | Experiment and failure criterion |
|---|---|---|
| T01 | Group-max conformal mutation contracts reduce wrong emitted edges without losing more than 20% of correct edges. | Fit nonconformity 1-p(gold), taking the maximum per retained calibration component, at alpha=0.10. Use rank ceil((m+1)(1-alpha)); ranks above m yield the universal label set. Emit only singleton positive-edge labels. Compare with few-shot argmax. Fails the operational target if errors do not decrease or correct-edge retention is below 0.80. Report row/group coverage, empty/multiple sets, and abstention. No deployment coverage guarantee is claimed. |
| T02 | Residual errors of the two formulations are positively dependent, limiting redundant verification. | Measure observed double faults minus the independence product, phi, same-wrong-label counts, and paired component-bootstrap interval. A nonpositive excess fails the point-estimate hypothesis; an interval crossing zero is unresolved. Report perfect-router accuracy only as an unattainable oracle bound, not a deployed router. |
| T03 | Enriched benchmark precision will deteriorate substantially when true edges are rare. | For same/SUPPORTS predictions, project PPV at prevalences 0.01, 0.05, 0.10 and 0.50 using observed sensitivity and false-positive rate. Target: at least a 0.10 precision drop at prevalence 0.01 relative to observed precision. Hold the negative-class mixture and conditional error rates fixed; these are sensitivity projections, not measured deployment results. |
| T04 | A component risk budget based on raw Jev scores controls family error better than a fixed per-edge gate. | Compare confidence >=0.95 against greedy descending-confidence admission satisfying sum(1-p)<=0.05 per predicted source component. Target: empirical any-error frequency <=0.05 among nonempty admitted components, with at least 80% correct-edge retention relative to the fixed gate. Failure, including errors assigned probability one, challenges the use of raw scores as valid risk bounds. |
| T05 | Topology-aware review prioritization cleans more correct-edge neighborhoods than uncertainty-only review. | Review ceil(0.10*n) positive candidate edges using uncertainty, uncertainty times one-hop edge impact, or random selection (128 seeds). An ideal reviewer removes incorrect reviewed edges only. Utility is the number of correct edges with no remaining incorrect edge incident to either endpoint. Target: strictly greater utility than uncertainty-only. Equal review cost and perfect reviewer assumptions limit conclusions. |
| T06 | A calibration-selected baseline-to-few-shot cascade saves at least 20% of recorded input tokens while losing at most 0.01 evaluation macro-F1. | Escalation thresholds: 0, .5, .7, .85, .9, .95, .99, 1, 1.000001; baseline errors always escalate. On purged calibration, choose the cheapest policy within 0.01 macro-F1 of all-few-shot, counting baseline plus escalated few-shot tokens. Lock the policy before evaluation. Report total hypothetical input-token cost, escalation, classification and edge outcomes. No new latency or billing claim. |
| T07 | Globally consistent identity decoding improves truth-level identity outcomes beyond greedy local merges. | In 256 seeded six-node worlds per arm, resample archived ER calibration scores conditional on synthetic pair truth. Compare exact partition optimization with greedy positive-log-odds agglomeration and order perturbations. Target: fewer false merges without more missed matches. Exact objective optimality alone is not evidence of better semantic accuracy; pairwise conditional independence and resampling are simulation assumptions. |
| T08 | Dependency-complete semantic caching avoids stale reuse while saving recomputation over global invalidation. | Simulate sparse source dependencies, absent-query buckets, and model/schema/policy changes. Compare input-only keys, keys omitting query-bucket generations, global-generation invalidation, and complete dependency fingerprints. Target: zero stale hits and more hits than global invalidation. The oracle is a context digest, not a Jev answer. Dependency completeness is an external assumption. |
| T09 | Alternative-proof compilation prevents unnecessary retraction while preserving necessary retraction. | Use actual GraphStore with P=(s0 AND s1) OR s2 and Q=P AND s3. Compile each sufficient proof as a separate assertion. Exhaust all 16 source-withdrawal subsets and compare with an independent Boolean oracle and flattened-AND / flattened-OR controls. Target: zero false removals or false retention. Synthetic invariant verification, not empirical extraction accuracy. |
| T10 | Observable query contracts detect semantic drift that type-valid schema migration alone permits. | Preview migrations in an isolated SQLite backup; enumerate predicate/endpoint query answers before and after. Include symmetry/inverse changes and observationally benign additions. Target: reject all observed query-changing migrations, accept benign ones, and leave the original database unchanged. A finite query contract does not establish universal semantic equivalence. |

## Reproduction and reporting requirements

Provide a standard-library runner, focused unit/integration tests, machine-readable results, an automatically generated analysis, input hashes, fixed recipes, and read-only CI on Linux and Windows. Test invalid inputs, deterministic ties, calibration/evaluation separation, conditional/simulated evidence labels, and retraction/migration invariants. Preserve costs and missing/error observations rather than silently inventing values. Review the diff and existing CI before merging. Separate code correctness from whether a hypothesis is supported.
